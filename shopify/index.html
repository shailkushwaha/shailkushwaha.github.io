Free resource

20 When / If / Then prompts for Shopify Flow

Copy a sentence into Sidekick inside Shopify Flow and it drafts the workflow for you. Each one is named after the problem it solves, so a merchant can find the one they need.

Before you turn any of these on: Sidekick saves new workflows switched off. Read each box, change the numbers and email addresses to suit your store, and test on a draft product first. Some actions (marketing emails, for example) need Shopify Email or another app installed, and available options can vary by plan.
How I teach

Explain, demonstrate, then let them try

The posting asks for a teacher's instinct for when to do which. Here's how my video uses all three.

Explain

Name the idea first

One rule a merchant can remember: When something happens, If something is true, Then do something. I show where everyday speech mixes the When and the If.

Demonstrate

Show it in the real tool

I type the sentence into Sidekick, open each box Sidekick builds, then test it on a draft product so the merchant sees it work.

Let them try

Hand it over

The video ends with a challenge: write the sentence for tagging VIP customers. The merchant leaves able to build the next one on their own.
